# Multi-Platform Chat OBS Plugin

![Build Status](https://img.shields.io/badge/build-passing-brightgreen)
![License](https://img.shields.io/badge/license-MIT-blue)

Aggregate live chat from 19+ streaming platforms into a single OBS dock and browser source overlay!

## 🌟 Supported Platforms

YouTube • Twitch • Kick • Rumble • Gettr • Odysee • Pilled.net • Bigo Live • Instagram • Facebook • NimoTV • Retake.tv • SOOP • FC2 Live • Bitchute • DLive • Twitter • VK • Locals

## ✨ Features

- **Unified Chat Dock**: View all platform chats in one place
- **Browser Source Overlay**: Customizable on-screen chat display
- **Real-time Sync**: All platforms update simultaneously
- **Platform Badges**: Color-coded platform indicators
- **User Badges**: Owner, Moderator, Subscriber badges
- **WebSocket API**: Build custom integrations

## 📦 Installation

1. Download the latest release
2. Extract to OBS plugins folder
3. Restart OBS
4. Find "Multi-Platform Chat" in View → Docks

## 🚀 Quick Start

1. Click "Add Platform" in the dock
2. Select platform and enter channel ID
3. Add authentication token if required
4. Repeat for all platforms you want to monitor
