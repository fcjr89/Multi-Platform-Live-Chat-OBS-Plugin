# Multi-Platform Live Chat OBS Plugin

![Build Status](https://img.shields.io/badge/build-passing-brightgreen)
![License](https://img.shields.io/badge/license-MIT-blue)
![Platforms](https://img.shields.io/badge/platforms-19-orange)

**Aggregate live chat from 19+ streaming platforms into a single OBS dock and browser source overlay!**

## 🌟 Supported Platforms

**Fully Implemented:** YouTube • Twitch

**Ready for Implementation:** Kick • Rumble • Gettr • Odysee • Pilled.net • Bigo Live • Instagram • Facebook • NimoTV • Retake.tv • SOOP • FC2 Live • Bitchute • DLive • Twitter/X • VK • Locals

## ✨ Features

- Unified Chat Dock - View all platform chats in OBS
- Browser Source Overlay - Customizable on-stream display
- WebSocket API - Build custom integrations
- Real-time Sync - All platforms update simultaneously

## 📦 Installation

1. Download the latest release
2. Extract to OBS plugins folder
3. Restart OBS Studio
4. Open: View → Docks → Multi-Platform Chat
